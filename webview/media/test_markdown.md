## 5. 代码

### 行内代码
使用 `console.log()` 函数

### 代码块
```javascript
function hello() {
  console.log('Hello, World!');
}
```

### 带语言标识的代码块
```python
def greet(name):
    print(f'Hello, {name}!')
```
